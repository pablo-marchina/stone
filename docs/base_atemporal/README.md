# Base atemporal — espelho documental candidato

Este overlay não inclui a biblioteca integral privada nem os originais; as referências relativas do núcleo apontam para o pacote completo de contexto externo. Não interpretar este espelho como substituto autossuficiente das fontes. Não incluir arquivos institucionais/Stone sem direito de redistribuição. Fonte viva de runtime: código, PRs e logs; fonte de escopo: proposta, DEC e matrizes. Aplicar por branch revisável, nenhuma mudança de código/dados/gates. A baseline histórica preservada contém 204 IMP e 543 dependências.
