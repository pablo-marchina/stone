Aumentar a visibilidade dos componentes já implementados no prazo comunicado pelo responsável. Não alterar o Plano Único nem converter a demonstração em produção. IMP-055/057, IMP-074/075, IMP-078/174/175/184, CAP-002/005/007/023: evidência técnica parcial, sem aceite formal.

## Executar
No checkout desta branch, com as dependências Python previamente instaladas:
```powershell
$env:PYTHONPATH = Join-Path (Get-Location).Path "src"
python -m scripts.demo_stone
```

Escolha uma senha local de pelo menos 12 caracteres no terminal. Abra http://127.0.0.1:8765/app/demo.html, organização stone-demo, usuário demo, senha escolhida. Nenhuma senha real, banco operacional ou token é necessário. O servidor escuta apenas loopback, sem proxy headers; Ctrl+C descarta o banco temporário. Os rascunhos são persistidos durante a sessão, não após a exclusão do banco. Em caso de porta ocupada, use --port 8766.

A interface consulta o ranking SQL, desenha a distribuição dos dez primeiros e compara as médias do top 10% e restante. Permite inspecionar snapshot e métricas de uma referência, executar seis passos do agente, obter cinco propostas determinísticas, selecionar uma delas, criar documento persistido, editar título por ETag, exportar SVG/PNG com SHA-256 e abrir a biblioteca do Studio completo. Dados de origem fictícia e limitações científicas são explícitos; nenhum direito de mídia, autorização de publicação ou gate é conferido.
