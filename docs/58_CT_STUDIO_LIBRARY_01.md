# CT-STUDIO-LIBRARY-01 — CAP-023, biblioteca privada de rascunhos

GET /v1/studio/documents: sessão bearer existente, tenant derivado exclusivamente da sessão; qualquer papel com acesso de leitura ao Studio. Query limit inteiro 1..50 (20), after Id opcional, ordenação lexical por document_id, cursor exclusivo, sem total; novas inserções entre páginas podem alterar a vista, não snapshot de consulta. Response studio-draft-library.v1, items (ID, versão, título da primeira página truncado em 120 caracteres, número de páginas, formato, estado draft, direitos pendentes, referência não verificada, resumo de recibo histórico, contagem histórica e hipótese quando consistente), next_after. Cache-Control private, no-store. Sem IDs de fontes, texto bruto de publicações, hashes, segredos, payload de evento ou nova autorização; nenhum acesso externo. Recibo validado por evento/outbox, versão inicial, identidade de documento pelo hash e conjunto ordenado de referências; não equivale a validade atual de grant nem comprovação de direitos. Falta/inconsistência sinalizada. 401 sem sessão, 422 parâmetros inválidos, 409 revisão inválida; isolamento tenant: outros documentos não aparecem. UI usa textContent, limpa lista no logout, paginação, seleção e proteção de texto pendente. GET sem mutação. Teste de contrato: autenticação, isolamento, paginação, revisão, falha de recibo. Sem migração, sem release de produção.
